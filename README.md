
# GCC Compass

GCC Compass is an AI-powered application designed to help users explore Global Capability Centres (GCCs), market indicators, and relevant research insights.

## Features
- Explore company information
- Review GCC market indicators
- Access research data
- Interactive Streamlit interface

## Tech Stack
- Python
- Streamlit
- Pandas
- AI integration

## Run Locally
1. Install the dependencies:
   pip install -r requirements.txt
2. Start the app:
   streamlit run app.py

## Data
The application uses CSV datasets stored in the `data/` directory.
